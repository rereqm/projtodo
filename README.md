# Портал командировок и расходов (MVP)

## Назначение приложения
Веб-приложение для сотрудников компании, позволяющее планировать командировки и вести учёт командировочных расходов. Включает в себя управление поездками и фиксацию затрат (билеты, отели и т.д.).

## Реализованные экраны (Лабораторная №1)
1. **Экран «Расходы»** — список всех расходов. Отображает название траты, сумму, статус утверждения бухгалтером и дату.
2. **Экран «Командировки»** — список поездок в виде сетки карточек. Отображает направление, цель поездки и выделенный бюджет.
3. **Общий каркас (Layout)** — верхняя панель навигации для переключения между экранами.

*(В планах на следующие лабораторные: интеграция с бэкендом, авторизация, а также модуль OCR для автоматического распознавания чеков).*

## Технологический стек
*   **Frontend:** React, TypeScript, Vite, React Router, Mantine UI.
*   **Структура:** Feature-Sliced Design (упрощенная).


1. Откройте терминал и перейдите в папку с фронтендом:
   cd frontend
2.Установите все необходимые зависимости:
   npm install
3.Запустите сервер для локальной разработки:
   npm run dev
4.После успешного запуска откройте браузер и перейдите по адресу:
http://localhost:5173
